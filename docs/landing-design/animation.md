# AquaFleet Landing Page
## Motion & Interaction Specification

**Scope:** Unauthenticated landing / authentication experience only  
**Project:** AquaFleet — Marine Research Fleet Management System  
**Branch:** `feature/landing-redesign`

---

# 1. Purpose

This document defines how AquaFleet's redesigned landing page should move and behave.

The objective is to create a subtle cinematic marine experience without sacrificing:

- authentication usability;
- accessibility;
- performance;
- readability;
- professional appearance.

Motion should support the perception of a living marine research environment.

It must never make the page feel like a game, military simulator, or excessive visual demo.

---

# 2. Motion Philosophy

The overall motion language should be:

> slow, deliberate, atmospheric, scientific, and restrained.

The interface should feel alive even when the user is not interacting with it.

Most continuous motion should be extremely subtle.

Animation hierarchy:

```text
Ocean motion
    ↓
Vessel movement
    ↓
Wake motion
    ↓
Radar movement
    ↓
HUD micro-motion
    ↓
UI entrance

Interactive feedback
